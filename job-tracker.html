使用说明 / 数据备份
· 状态流转：未投递 → 已投递 → 有反馈 → 面试中 → Offer / 已结束，卡片上的下拉框可随时改。
· 快捷记录：「今日投递」一键写入当天日期；「记反馈」写入反馈日期并自动进入「有反馈」。
· 无反馈提醒：已投递超过 7 天仍无反馈，卡片会出现黄色提示条。
· 删除 = 移入「不感兴趣 / 不合适」库：点卡片「删除」不会真的丢，公司会存到页面底部的库里 （点标题栏展开，点页面其他地方自动收起），可随时「恢复」；确定不要了再在库里点「彻底删除」。 批量删除同样是移入库。
· 备份：点「导出备份」下载 JSON，换机器时用「导入」恢复；「导出 CSV」可用 Excel 打开。
· 投递材料：只记录文件的本机完整路径（不复制文件内容），点「打开」直接调起简历 / 项目集；「目录」打开所在文件夹，「复制路径」粘贴到招聘网站上传框。请双击本 HTML 文件用浏览器打开（地址栏 file:// 开头）才能跳转本地文件。
· 预置网址：内置 130+ 家公司官方社招页，按「游戏大厂 / 游戏中厂新锐 / 游戏小厂工作室 / 电竞·直播·社区 / 互联网大厂 / 互联网中厂 / AI / 车企 / 金融」分类。招聘站点域名会变动，失效时点卡片「编辑」改地址；少数公司只收录了官网主站，进去后找「加入我们 / 招聘」入口。
· 存储位置：浏览器 localStorage，键名 jobtrack.v1。清理浏览器数据会一并清空，请定期导出。
