# 育卓的个人站

一个纯前端、无需服务器的个人工具合集网站。

**在线访问：** https://ezioxx7.github.io/yuzhuo-site/

## 包含工具

- **首页 / 个人主页**：可实时编辑所有模块与文字，自动保存到浏览器本地。
- **网文写作助手**：写作打卡、字数统计、大纲管理等，数据保存在浏览器 IndexedDB 中。
- **求职追踪**：投递记录、进度管理，数据保存在浏览器 localStorage 中。

## 使用方法

- 在线访问：直接打开上面的网址即可（GitHub Pages 托管）。
- 本地运行：用浏览器打开 `index.html`，无需安装任何依赖或启动服务器。

## 技术栈

- 原生 HTML / CSS / JavaScript（单文件应用）
- 数据全部保存在浏览器本地（localStorage / IndexedDB），不上传任何服务器
